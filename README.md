##Description

The miniRT project is an introduction to the beautiful world of Ray Tracing. The goal is to render simple computer-genetared images and implement mathematical formulas.

##Instructions

To run this program, you will need the minilibx-linux. you can download it here : 
https://cdn.intra.42.fr/document/document/46599/minilibx-linux.tgz

unzip it in the "minilibx-linux" folder.

type "make" and then start the program with the following format : 

./miniRT yourfile.rt

there are some .rt files available for example in the /scenes folder.

Press ESC or click the little cross to end the program.

##Resources

The project was made following "The Ray Tracer Challenge" a book by Jamis Buck.
AI was used to understand the mathematics behind the ray tracer and concepts from the book.
